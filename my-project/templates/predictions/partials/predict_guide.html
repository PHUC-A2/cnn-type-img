Hướng dẫn phân loại ảnh

Upload một ảnh, chọn mô hình CNN đã huấn luyện — hệ thống trả về nhãn và xác suất từng class.

  • Điều kiện: Cần ít nhất một mô hình CNN đã huấn luyện xong và có phiên bản Production (file .h5 sẵn sàng). Xem tại Mô hình CNN.
  • Chọn mô hình: Dropdown chỉ liệt kê model bạn có quyền dùng và đã sẵn sàng predict. Mỗi model gắn với bộ class của dataset đã huấn luyện.
  • Ảnh upload: {{ allowed_image_ext_display }} — tối đa {{ max_image_mb }}MB. Hỗ trợ kéo thả hoặc bấm chọn file.
  • Top-K: Số class hiển thị trên biểu đồ xác suất (mặc định 3, tối đa 20). Top-1 là nhãn có xác suất cao nhất.
  • Tiền xử lý: Ảnh được resize theo kích thước input của model, chuyển RGB và chuẩn hóa pixel (÷255) trước khi đưa vào CNN.

Ảnh cho kết quả tốt

  • Cùng loại đối tượng đã huấn luyện (ví dụ chó/mèo nếu model train cho-meo)
  • Đủ sáng, không mờ, không bị che khuất quá nhiều
  • Đối tượng chính nằm gần trung tâm khung hình
  • Một ảnh một đối tượng cần phân loại

Tránh các trường hợp

  • Ảnh không thuộc class nào model đã học
  • File corrupt, 0 byte hoặc sai định dạng
  • Chọn model chưa huấn luyện xong / chưa có file .h5
  • Ảnh quá lớn vượt {{ max_image_mb }}MB

Quy trình nhanh

(1) Huấn luyện model từ dataset → (2) Kiểm tra model có badge Production → (3) Vào trang này, chọn model → (4) Upload ảnh → (5) Bấm Phân loại ảnh → (6) Xem nhãn, độ tin cậy và biểu đồ xác suất.

Kết quả được lưu vào hệ thống — bạn có thể xem lại chi tiết tại trang kết quả sau mỗi lần phân loại.
