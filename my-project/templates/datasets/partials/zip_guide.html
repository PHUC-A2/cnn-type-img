{# Alert hướng dẫn tải file ZIP và cấu trúc thư mục class bên trong #}

Hướng dẫn tải bộ dữ liệu đúng định dạng

Chỉ chấp nhận file .zip có cấu trúc thư mục theo class trước khi huấn luyện CNN.

  • Định dạng file: Chỉ upload file ZIP (tối đa {{ max_zip_mb }}MB). Không dùng RAR, 7z hay thư mục nén lồng nhau phức tạp.
  • Cấu trúc bắt buộc: Mỗi thư mục con trực tiếp là một class (nhãn), bên trong chứa ảnh. Cần ít nhất {{ min_classes }} class và mỗi class có tối thiểu {{ min_images_per_class }} ảnh hợp lệ.
  • Định dạng ảnh: {{ allowed_image_ext_display }}. Ảnh corrupt hoặc 0 byte sẽ bị bỏ qua / báo lỗi khi xử lý.
  • Đặt tên class: Dùng tên thư mục rõ nghĩa (ví dụ cho, meo). Tên thư mục sẽ trở thành nhãn phân loại khi huấn luyện.
  • Thư mục bọc ngoài: Nếu ZIP có một thư mục gốc duy nhất (ví dụ cho-va-meo/cho/...), hệ thống vẫn tự nhận diện được.
  • Khuyến nghị: Mỗi class nên có từ 4 ảnh trở lên (càng nhiều càng tốt) để mô hình CNN học ổn định hơn.

Cấu trúc đúng 

cho-va-meo.zip
├── cho/
│   ├── cho_001.jpg
│   ├── cho_002.jpg
│   └── cho_003.png
└── meo/
    ├── meo_001.jpg
    └── meo_002.jpg

Cấu trúc sai (thường gặp)

  • Ảnh nằm trực tiếp trong ZIP, không có thư mục class
  • Chỉ có 1 class — không đủ để phân loại
  • Thư mục class rỗng hoặc chỉ chứa file .txt / .pdf
  • Nén cả thư mục cha lẫn nhiều tầng không có ảnh ở tầng class

Quy trình nhanh

(1) Chuẩn bị thư mục trên máy → (2) Mỗi class một folder riêng → (3) Nén thành .zip → (4) Bấm Tải lên và đặt tên bộ dữ liệu.
